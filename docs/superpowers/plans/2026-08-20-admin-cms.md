# Admin Workspace And Page CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a role-aware `/admin` workspace that separates all management from public reading and adds a page CMS with unlimited content pages plus one configurable Todo, Movie, Links, and Guestbook page.

**Architecture:** Keep the existing Flask application and public route module, but add a dedicated `admin` Blueprint split into focused route modules. Persist authorization in `User.role`, centralize ownership/role/page mutations in service modules, and use `Page` plus `PageRedirect` for CMS metadata while retaining the existing module-entry tables. Public fixed routes become read-only compatibility entry points and a final `/<slug>` resolver renders the current canonical content or module page.

**Tech Stack:** Flask 3.1, Flask-Login, Flask-WTF, Flask-SQLAlchemy 3.1, SQLAlchemy 2.0, Alembic/Flask-Migrate, MySQL with PyMySQL, isolated SQLite tests, Jinja2, Bootstrap compatibility, vanilla CSS/JavaScript, pytest, in-app browser verification.

## Global Constraints

- The only roles are `user` and `admin`; new registrations always receive `user`.
- Every logged-in user can enter `/admin`; ordinary users can create and manage only their own articles.
- Administrators can manage all articles, pages, categories, comments, guestbook entries, module data, and user roles.
- Administrators cannot demote themselves or the final administrator.
- Database roles become authoritative after migration; `ADMIN_EMAILS` is used only to backfill the first persisted administrators.
- Public pages retain reading, likes, comments, profiles, follows, and messages, but contain no create, edit, delete, or moderation controls.
- Support unlimited `content` pages and exactly one non-deletable `module` page for each of `todo`, `movie`, `links`, and `guestbook`.
- Preserve `/todo`, `/movie`, `/links`, `/comment`, and `/about`; old slugs redirect to the current canonical page URL.
- Reject reserved slugs including `admin`, `login`, `logout`, `register`, `post`, `user`, `static`, `files`, `upload`, and `rss`.
- Unpublished pages return `404` publicly and remain previewable to authorized administrators.
- All mutations use POST, Flask-WTF CSRF protection, transaction rollback on failure, and server-side authorization.
- Keep the current Apple-style monochrome light/dark design and use compact admin typography and controls.
- Do not add a frontend framework or replace the existing global Flask application with an app factory during this feature.
- Run every Python test command exactly with `DATABASE_URL=sqlite:// .venv/bin/python -m pytest ...`; never source `.env` for tests.
- Before applying migrations to MySQL, back up the `flog` database and inspect the generated SQL; never use the production database for automated tests.

```python
# app/authorization.py
import sqlalchemy as sa
from flask import abort
from app import db
from app.models import Post, User

ROLE_USER = 'user'
ROLE_ADMIN = 'admin'
VALID_ROLES = frozenset({ROLE_USER, ROLE_ADMIN})


class RoleChangeError(ValueError):
    pass


def owned_post_or_404(post_id, actor):
    query = sa.select(Post).where(Post.id == post_id)
    if not actor.is_admin:
        query = query.where(Post.user_id == actor.id)
    post = db.session.scalar(query)
    if post is None:
        abort(404)
    return post


def change_user_role(actor, target, new_role):
    if not actor.is_admin:
        raise RoleChangeError('Administrator access is required.')
    if new_role not in VALID_ROLES:
        raise RoleChangeError('Unknown role.')
    if target.role == ROLE_ADMIN and new_role == ROLE_USER:
        admins = db.session.scalars(
            sa.select(User).where(User.role == ROLE_ADMIN).with_for_update()
        ).all()
        if len(admins) <= 1:
            raise RoleChangeError('The final administrator cannot be demoted.')
    if actor.id == target.id and target.role == ROLE_ADMIN and new_role != ROLE_ADMIN:
        raise RoleChangeError('You cannot remove your own administrator role.')
    target.role = new_role
```

Add the mapped role column with a server default of `user`, a `user/admin` check constraint, and change `User.is_admin` to `return self.role == ROLE_ADMIN` without reading Flask config. Update `admin_required` to check only the persisted property.
Keep the literal role default/check values in `app/models.py`; do not import `app.authorization` from the model module because `app.authorization` already imports `User` and `Post`.

def normalize_slug(value):
    normalized = unicodedata.normalize('NFKD', value or '')
    ascii_value = normalized.encode('ascii', 'ignore').decode('ascii').lower()
    slug = re.sub(r'[^a-z0-9]+', '-', ascii_value).strip('-')
    if not slug:
        raise PageValidationError('Slug must contain letters or numbers.')
    if slug in RESERVED_SLUGS:
        raise PageValidationError('This slug is reserved by the system.')
    return slug

@app.route('/<slug>', methods=['GET', 'POST'])
def public_page(slug):
    resolved = page_for_public_slug(slug)
    if resolved is None:
        abort(404)
    page, is_redirect = resolved
    if not page.is_published:
        abort(404)
    if is_redirect:
        return redirect(url_for('public_page', slug=page.slug), code=301)
    if request.method == 'POST' and page.module_key != 'guestbook':
        abort(405)
    return render_public_page(page)
